# Business Model Canvas (proposed hypotheses - no existing agreements)

1. **Customer segments** - hospitals; hospital networks; healthcare warehouses; public healthcare procurement organisations; pharmaceutical distributors.
2. **Value propositions** - early stock-out/expiry warning with reasons; feasible cost-minimal redistribution; human-approved, auditable recovery; scenario what-ifs.
3. **Channels** - pilots via hospital networks/procurement bodies; SAP ecosystem/partner events (if a partnership is later agreed); direct demos.
4. **Customer relationships** - onboarding + configuration support; quarterly review of forecast/policy performance; community of practice.
5. **Revenue streams** - SaaS subscription per facility; implementation/integration fees; premium analytics; (all unvalidated pricing).
6. **Key resources** - forecasting/optimization engine; data connectors; domain expertise; cloud hosting.
7. **Key activities** - model tuning and validation, connector development, security/compliance, customer success.
8. **Key partnerships (to explore)** - ERP vendors/integrators (e.g. SAP partner route), hospital networks for pilots, cold-chain logistics providers, medical associations.
9. **Cost structure** - engineering, cloud, integration support, security audits, sales/pilots.
